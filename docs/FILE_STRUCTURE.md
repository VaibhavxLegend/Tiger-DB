# Project File Structure

Complete directory structure for the TigerGraph Agentic Fraud Investigation system.

```
tigergraph-fraud-agent/
│
├── README.md                          ✓ Setup and run instructions
├── .env                               ✓ TigerGraph and API credentials (gitignored)
├── .env.example                       ✓ Template for environment variables
├── .gitignore                         ✓ Git ignore rules
├── requirements.txt                   ✓ Python dependencies
│
├── docs/                              # Planning and spec documents
│   ├── PHASE_0_SUMMARY.md             ✓ Phase 0 verification results
│   ├── SPEC_PROMPTS.md                ✓ LLM prompt specifications
│   ├── assumptions.md                 ✓ Implementation assumptions log
│   └── FILE_STRUCTURE.md              ✓ This document
│
├── data/
│   ├── raw/                           # Original datasets (provided)
│   │   ├── README.md                  ✓ Dataset documentation
│   │   ├── transactions.csv           ✓ 590,742 transactions
│   │   ├── identity.csv               ✓ 144,432 device records
│   │   ├── case_pack.csv              ✓ 20 benchmark cases
│   │   └── closed_cases_history.csv   ✓ 5,565 closed cases
│   ├── policy/                        # Policy documents for RAG
│   │   ├── fraud_policy.md            ✓ Authoritative policy rules
│   │   ├── fraud_typologies.md        ✓ 5 known fraud patterns
│   │   └── regulatory_references.md   ✓ FinCEN, FATF guidelines
│   └── processed/                     # Pre-processed data for loading
│       └── closed_cases_history_exploded.csv  (generated by scripts/preprocess)
│
├── graph/                             # TigerGraph GSQL files
│   ├── schema/
│   │   ├── create_vertices.gsql       ⏳ Transaction, Card, Customer, Device, etc.
│   │   ├── create_edges.gsql          ⏳ MADE_BY, OWNED_BY, USES_DEVICE, etc.
│   │   └── create_graph.gsql          ⏳ Graph definition
│   ├── loading_jobs/
│   │   ├── load_transactions.gsql     ⏳ Load transactions.csv
│   │   ├── load_identity.gsql         ⏳ Load identity.csv
│   │   ├── load_case_pack.gsql        ⏳ Load case_pack.csv
│   │   └── load_closed_cases.gsql     ⏳ Load exploded closed cases
│   ├── queries/                       # Installed GSQL queries
│   │   ├── get_txn_neighborhood.gsql  ⏳ K-hop neighborhood
│   │   ├── find_shared_devices.gsql   ⏳ Device clusters
│   │   ├── find_shared_cards.gsql     ⏳ Linked cards
│   │   ├── velocity_check.gsql        ⏳ Transaction velocity
│   │   └── get_similar_past_cases.gsql ⏳ Case retrieval
│   └── algorithms/
│       └── algo_configs.json          ✓ WCC, Louvain, PageRank configs
│
├── mcp_server/                        # MCP tool layer
│   ├── server.py                      ⏳ MCP server implementation
│   ├── tool_definitions.py            ⏳ Pydantic schemas for tools
│   └── config.yaml                    ✓ Tool catalog
│
├── rag/                               # Vector store and retrieval
│   ├── policy_ingest.py               ⏳ Ingest policy docs to vector store
│   ├── case_memory_embed.py           ⏳ Embed closed case narratives
│   ├── retriever.py                   ⏳ Hybrid graph + vector retrieval
│   └── vector_store/                  (generated by ChromaDB)
│
├── agent/                             # LangGraph state machine
│   ├── state.py                       ✓ CaseState definition
│   ├── graph.py                       ⏳ LangGraph workflow
│   ├── policy_engine.py               ✓ Deterministic approval routing
│   ├── nodes/                         # State machine nodes
│   │   ├── trigger.py                 ⏳ Initialize case
│   │   ├── investigate.py             ⏳ Call MCP tools
│   │   ├── assess_uncertainty.py      ⏳ LLM: risk/confidence
│   │   ├── gather_more_evidence.py    ⏳ LLM: evidence request
│   │   ├── recommend_action.py        ⏳ LLM: next-best-action
│   │   ├── explain.py                 ⏳ LLM: explanation + SAR
│   │   └── update_memory.py           ⏳ Write to graph + vector
│   ├── schemas/                       # Pydantic output schemas
│   │   ├── assessment.py              ✓ AssessmentOutput
│   │   ├── evidence_request.py        ✓ EvidenceRequestOutput
│   │   ├── action_recommendation.py   ✓ ActionRecommendationOutput
│   │   └── explanation.py             ✓ ExplanationOutput
│   └── prompts/                       # LLM prompt templates
│       ├── assess_prompt.md           ✓ Assess uncertainty prompt
│       ├── gather_evidence_prompt.md  ✓ Evidence request prompt
│       ├── nba_prompt.md              ✓ Next-best-action prompt
│       └── explain_prompt.md          ✓ Explanation prompt
│
├── actions/                           # Mock action APIs
│   ├── api.py                         ⏳ FastAPI endpoints
│   └── mock_responses.py              ✓ Response simulators
│
├── ui/                                # Next.js dashboard
│   └── (to be created in Phase 5)
│
├── evaluation/                        # Benchmark runner
│   ├── run_benchmark.py               ⏳ Run all 20 cases
│   └── output/                        # Case output files
│       └── *.json                     (generated: HHG-001.json, etc.)
│
├── scripts/                           # Setup and utility scripts
│   ├── setup_savanna.sh               ✓ Test TigerGraph connection
│   ├── preprocess_closed_cases.py     ⏳ Explode list columns
│   ├── load_all_data.sh               ✓ Run all GSQL DDL and loading
│   └── seed_case_memory.py            ⏳ Load closed cases to vector store
│
└── submission/                        # Hackathon deliverables
    ├── blog_post.md                   ⏳ Technical blog post
    ├── demo_video_link.txt            ⏳ Demo video URL
    └── social_post_draft.md           ⏳ Social media posts

Legend:
✓ = File created and scaffolded
⏳ = Stub file created, implementation pending
```

- All policy files in `data/policy/`
- Repository structure scaffolded
- CSV headers verified
- TigerGraph connection confirmed

### Phase 1 (Next)

- `scripts/preprocess_closed_cases.py`
- `scripts/load_all_data.sh`

## Critical Dependencies

1. **data/raw/** files must exist before Phase 1
2. **graph/schema/** must be created before loading jobs
3. **graph/queries/** must be installed before MCP server starts
4. **data/policy/** docs must be ingested before agent runs
5. **agent/schemas/** must match prompt specifications exactly
6. **evaluation/output/** format must match benchmark requirements

## Files Not in Git

- `.env` (credentials)
- `venv/` (Python virtual environment)
- `rag/vector_store/` (ChromaDB data)
- `ui/node_modules/`, `ui/.next/` (Node.js builds)
- `data/processed/*.csv` (generated data)
